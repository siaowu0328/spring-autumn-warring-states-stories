# 故事裡的春秋戰國

一個供個人複習的繁體中文靜態網站，依「春秋／戰國 → 時期 → 典故」整理故事。每則典故包含背景、經過、後續影響、相關典故與來源；透過關聯了解故事之間的歷史脈絡或可比較之處。各時期的前、中、後期為方便閱讀的整理方式，並非唯一分期標準。

## 專案結構

```text
.
├── AGENTS.md          給 AI 與協作者的擴充規則
├── README.md          專案介紹與使用方式
├── index.html         網站入口
├── assets/
│   ├── hero.png       網站主視覺的歷史風格插畫
│   ├── style.css      版面、紙張感與色塊設計
│   └── app.js         時期、故事與互動介面
└── data/
    └── stories.js     時期與典故資料
```

## 使用方式

下載專案後，用瀏覽器開啟 `index.html`。選擇「春秋」或「戰國」，再選擇想複習的時期與典故。文章中的相關故事可繼續延伸閱讀；來源可供查核。專案使用原生 HTML、CSS 與 JavaScript，不需要安裝套件。

## 如何繼續新增典故

先請 AI 閱讀 [AGENTS.md](AGENTS.md)，例如：「依照專案規則新增一則春秋典故，附可核對的來源，並說明它與現有故事的關聯。」AI 可在 `data/stories.js` 增加一個符合格式的故事物件、指定現有時期 ID、填寫歷史內容與來源，並以既有故事 ID 建立關聯；頁面由同一套介面產生。詳細欄位、歷史查證原則及測試清單都在 `AGENTS.md`。

## 部署 GitHub Pages

1. 將完整專案上傳 GitHub 儲存庫，確認 `index.html` 位於儲存庫根目錄。
2. 在儲存庫的 **Settings → Pages**，選擇 **Deploy from a branch**，設定預設分支和 `/ (root)`，儲存。
3. 等待部署完成，開啟 GitHub 提供的網址，測試板塊、時期、故事及相關連結。

史料可能有不同記載；網站內附來源與必要的說明，供讀者繼續查核。
